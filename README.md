# Mini E-Commerce Website

Website e-commerce sederhana beserta basis datanya.

## Cara Menjalankan secara Lokal:
1. Clone repositori ini:
   `git clone https://github.com/USERNAME_KAMU/mini-ecommerce.git`
2. Import file `db_miniecommerce.sql` ke dalam MySQL / phpMyAdmin kamu.
3. Sesuaikan konfigurasi database di file koneksi (`config.php` / `.env`).
4. Jalankan website di web server lokal (Laragon / XAMPP / Apache).
